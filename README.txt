چادری برزکار — نسخه نمایشی قابل انتشار

فایل‌ها:
- index.html: صفحه فروشگاه
- admin.html: پنل مدیریت جداگانه

انتشار در GitHub Pages:
1) هر دو فایل را در ریشه مخزن GitHub قرار بده.
2) در Settings > Pages، گزینه Deploy from a branch را انتخاب کن.
3) Branch را روی main و Folder را روی /(root) بگذار و Save کن.
4) پس از انتشار، پنل از مسیر /admin.html باز می‌شود.

امکانات تنظیمات پنل: مدیریت محصولات، متن نوار بالایی، نام و شعار فروشگاه، متن‌های بنر اصلی، تصویر بنر اصلی، بنر دوم، نشانی و راه ارتباطی، و متن معرفی پایین سایت.

محدودیت‌های مهم:
- این نسخه از localStorage مرورگر استفاده می‌کند. تغییرات فقط در همان مرورگر و همان دستگاه ذخیره می‌شوند؛ مشتریان دیگر آن‌ها را نمی‌بینند.
- تصویر بنر و تصاویر محصولات ممکن است فضای ذخیره مرورگر را پر کنند؛ تصاویر کم‌حجم استفاده کن.
- رمز پنل فقط یک قفل نمایشی در فایل‌های سمت مرورگر است. چون کد GitHub Pages عمومی است، فرد فنی می‌تواند آن را دور بزند. برای امنیت واقعی باید از احراز هویت و پایگاه داده سمت سرور استفاده شود.
- سبد خرید، ثبت سفارش و پرداخت درگاه واقعی هنوز آزمایشی هستند.
- پرو مجازی هوش مصنوعی واقعی هنوز متصل نیست؛ فقط پیش‌نمایش تصویر است.
